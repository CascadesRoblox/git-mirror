Create a Token

  1. Please sign in with your GitHub account.
  2. Set the note to something along the lines of "git-mirror Token."
  3. For hobby projects, set the expiration date to a set amount, otherwise it is recommended to set it to never expire (not as safe if it gets leaked).
  4. Make sure you click the following permissions: repo, admin:org (required for organization repos).
  5. Press create and enter the token given by GitHub below.
  6. Press Enter.
